Runs entirely in your browser sandbox

Files are read with the File API and hashed with SubtleCrypto (or an in-memory pure-JS implementation for MD5 / SHA-3). No network request, no upload, no server — ever. You can disconnect from the internet after the page loads and it still works.

Why algorithm choice matters

MD5 and SHA-1 are broken against deliberate collision attacks: two different files can be crafted to share the same digest. They're fine for accidental-corruption checks, but don't rely on them to verify a file wasn't tampered with. SHA-256, SHA-512 and SHA-3 have no known practical collision attacks.

Installable, works offline

HashSentinel is a Progressive Web App. Install it to your device and it keeps working with no connection at all — the whole tool, including the MD5 / SHA-3 engines, is cached locally.
